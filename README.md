# hyperion-android-grabber
Screen grabber for hyperion

This application will send the content of an android screen to a hyperion instance to handle the image.

> **2026-11-16: WLED direct mode is in development and not released.**
> The current repository still contains the legacy Hyperion TCP backend. No signed APK,
> device installation, hardware acceptance or release has been completed.
