# 原生界面组件审查（2026-11-19）

审查对象是 `mobile`、`tv`、`common` 三个模块的 Android Views。盘点依据为三个 manifest、9 个布局 XML、手机菜单及通过 Java/Kotlin 创建的控件，而非网页扫描。请求未附初筛条目；下表记录从当前源码独立核实的内容，不代表已核销一份未收到的清单。

## 组件与入口

| 界面 | 实际组件及边界 |
|---|---|
| 手机首页、设置、快捷磁贴 | 首页图标和菜单；`SettingsActivity` 动态生成 `EditText`、`CheckBox`、语言 `Spinner`；`WledTileService` 是独立系统入口。空配置引导和保存契约不变。 |
| TV 首页、连接、发现结果 | 首页图标和启动设置；连接/高级设置使用 Leanback GuidedStep；设备扫描、结果确认各有独立 Activity。动画不是设备探测或保存成功的判据。 |
| TV 布局编辑 | 双栏 `ScrollView`、`LayoutValueRow`、精确输入对话框和内联预览；改变草稿与提交配置是两个不同动作。 |
| 两端共享 | 授权确认、启动设置、`LedLayoutPreviewView`、测试图案页及首页背景。此次不改变系统授权、服务状态来源、设备输出或待机策略。 |
