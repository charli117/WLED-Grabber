## 未执行 / 仍阻塞

- 连续 100 次 resize/旋转：本机每次强制显示配置变更都会触发 Sony SystemUI 的 `InfoBoard` 自身崩溃（`IllegalStateException: Task already scheduled or cancelled`），应用进程不受影响；未执行高频循环。CAP-2 保持待验证。
- API 34 单应用窗口 resize：本机 API 29，无 `onCapturedContentResize`。
- 系统主动撤销活跃投屏：API 29 无 `cmd media_projection` 入口。
- 真实断网/丢包/乱序：无 root，切断网络会同时断开 adb。
- 物理 FPS / 端到端 p95：无光感/高速相机；未用 `info.leds.fps` 替代。
- RGBW 样机两模式、500/1000/2000 灯、ESP8266：无硬件。

结论：真机可执行的采集生命周期、授权拒绝、resize/旋转、停止释放、进程被杀、WLED 重启恢复与冷启动均已取得原始证据；CAP-2 的 100 次循环/API34 项与 QA-2 的物理测量/RGBW/多灯数仍阻塞，不升级状态。
