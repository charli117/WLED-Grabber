## 本轮修复的两个测试基建问题

1. **测试 APK targetSdk = 21**：`common/build.gradle` 缺 `targetSdk`，androidTest APK 以
   21 打包，Android 14 会对 targetSdk < 23 的应用弹出 `ACTION_REVIEW_PERMISSIONS`
   复核页并盖住被测 Activity，导致 `StartupSetupActivityTest` 全部 45s 超时。
   已在 common 的 `defaultConfig` 补 `targetSdk 35`，API 34 common 恢复 38/38。
2. **平台 API 守卫**：`MobileEntriesInstrumentedTest` 的 TileService(API 24+)与
   NotificationChannel(API 26+)在 API 21 上不存在，已加 `assumeTrue` 跳过。
